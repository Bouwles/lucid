# Outpost credits

All art and sound in `assets/` comes from Kenney's **Starter Kit FPS**
(https://github.com/KenneyNL/Starter-Kit-FPS, by Kenney, kenney.nl). The kit's README says:
"Assets included in this package (2D sprites, 3D models and sound effects) are CC0 licensed"
(https://creativecommons.org/publicdomain/zero/1.0/). The kit's code is MIT licensed; Outpost
uses none of it. Files are copied unchanged.

Source URLs are `https://raw.githubusercontent.com/KenneyNL/Starter-Kit-FPS/main/<path>`.
