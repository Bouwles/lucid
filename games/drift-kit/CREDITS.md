# Drift Kit credits

All 3D models, the texture and the sounds in `assets/` come from Kenney's **Starter Kit Racing**
(https://github.com/KenneyNL/Starter-Kit-Racing), by Kenney (https://kenney.nl).
The kit's README says "3D Models & sounds _(CC0 licensed)_", and its licence section says the
assets "(2D sprites, 3D models and sound effects) are [CC0 licensed](https://creativecommons.org/publicdomain/zero/1.0/)".
The skid sound was made by Landeplage (https://github.com/Landeplage) and is also CC0.
Only the assets are used; none of the kit's (MIT-licensed) code is.

Files are unchanged copies. At load time the game leaves out the guard rails of the track tiles
so cars can run onto the grass.
