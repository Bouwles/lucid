# Bramble credits

Bramble uses art and sound from Kenney's **Starter Kit 3D Platformer**
([github.com/KenneyNL/Starter-Kit-3D-Platformer](https://github.com/KenneyNL/Starter-Kit-3D-Platformer)), by Kenney
([kenney.nl](https://kenney.nl)). The kit's README states that its sprites, 3D models and sound effects are licensed
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/) (public domain, no attribution required; credited here as
thanks). The kit's code is MIT licensed and is not used: Bramble's code is written from scratch.

Files are copied unchanged from the repository's `main` branch. Tints, scaling and animation are applied in code.
